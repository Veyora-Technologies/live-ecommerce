# Furnivo — Consumer Guide

1. **Open Furnivo** on your phone: `https://live.example.com`
2. **Allow location** or pick area (Wuse, Garki, etc.)
3. **Search**: type “Paracetamol near me” or “Rice in stock in Wuse” — use filters (Open now, In stock, Price)
4. **Check details**: price, distance, open status, last confirmed, verification badge
5. **Reserve**: choose quantity → “Reserve for pickup” → get code (e.g. LV-AB12-CD34) → expires in 24h, pay on pickup
6. **Track**: go to Activity to see Pending → Confirmed → Ready for pickup → Collected
7. **Save**: tap heart to save products; get alerts when back in stock (coming soon)
8. **Report**: if price wrong or closed, use Report (merchant reviewed by admin)

Tips: stale (grey) means merchant hasn’t confirmed recently — call/WhatsApp before going.

Need help? Contact merchant via Call/WhatsApp/ Directions buttons.
